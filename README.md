# パグパグオリンピック ～世界一のパグを目指せ！～

パグたちが世界一を目指す、スマホ向けの陸上競技ゲームです。
ファミコン時代の連打系スポーツゲームの熱さを、いまのスマホ向けUIで遊べるようにしました。

- 全7競技（100m走／110mハードル／走り幅跳び／やり投げ／走り高跳び／400m走／4×100mリレー）
- 大会モード（選手登録 → 予選 → 決勝 → 表彰式）
- 5種類のパグ選手（性能差は±4%程度のゆるい個性）
- CPU選手（初心者・中級者・上級者・世界チャンピオン）
- 難易度 EASY / NORMAL / HARD
- 記録室（自己ベスト・メダル・大会成績）
- PWA対応（ホーム画面に追加、オフラインで遊べる）
- 外部API・サーバー・画像/音声ファイル不要（絵も音もすべてプログラムで生成したオリジナル）

---

## 起動方法

### いちばん簡単な方法（PCで確認）
フォルダ内でローカルサーバーを起動してブラウザで開きます。

```bash
cd pug-olympic
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

`index.html` を直接ダブルクリックしても遊べますが、その場合 PWA・オフライン機能（Service Worker）は動きません。

### スマホで確認する場合
同じWi-Fi内のPCで上のサーバーを起動し、スマホから `http://<PCのIPアドレス>:8000` を開きます。
PWAとしてインストールするには HTTPS が必要なので、下の「公開方法」で GitHub Pages か Netlify に置くのがおすすめです。

## 操作方法

| 操作 | スマホ | PCキーボード |
|---|---|---|
| 走る（左右交互） | 画面下の「ひだり」「みぎ」を交互にタップ | ← → または Z X |
| ジャンプ・投げる・バトン等 | 中央の黄色/オレンジのボタン | Space / ↑ / Enter |
| 一時停止 | 右上の「II」 | — |

- 競技に必要なボタンだけが表示されます。
- 光っているボタンが「次に押す側」です。
- 同じボタンの連打ではほとんど加速しません。テンポには上限があり、機械的な超高速連打は有利になりません。
- 押しっぱなし（長押し）と連打は区別されます（キーボードのリピートは無視）。

## ゲームルール

### 共通
- 各競技はCPU選手5人（リレーは5チーム）と対戦し、順位が決まります。
- 3位以内でメダル獲得（金・銀・銅）。
- 自己ベスト更新・パグ世界記録更新で特別演出。
- 「パグ世界記録」はゲーム内の目標記録です。あなたが上回ると、以後はあなたの記録が世界記録になります。

### ① 100m走
「位置について」「よーい」「ドン！」の合図で左右交互タップ。合図前に押すとフライング（2回で失格）。

### ② 110mハードル
交互タップで走り、ハードル前で「ジャンプ」。ハードルの真上で最高点になるタイミングが PERFECT。PERFECTを続けるとコンボボーナスで加速。早すぎ・遅すぎは接触して減速、ジャンプしないと転倒。EASY/NORMALはレーンに理想の踏切ゾーン（緑）が表示されます。

### ③ 走り幅跳び（3回の試技・最高記録）
1. 交互タップで助走
2. 踏切板の手前で「ジャンプ」を長押し → 角度が上がる → 離して踏切（40°前後が◎）
3. 空中の最高点でタップ → 空中姿勢ボーナス
4. 着地直前にタップ → 足を前に出して着地（忘れると砂場にお腹から着地）
踏切線を越えるとファウル。評価：助走速度・踏切位置・角度・空中姿勢・着地。

### ④ やり投げ（3回の試技・最高記録）
1. 交互タップで助走 → パワーゲージがたまる
2. 「なげる」 → 角度メーターが振れる
3. ちょうどいい角度（40°前後）でもう一度タップしてリリース
ラインの近くで投げるほど◎、越えるとファウル。角度を決める間も体は少し進みます。

### ⑤ 走り高跳び
交互タップで助走 → 踏切ポイントで「ジャンプ」 → バーの真上で「背面」タップ。成功するたびにバーが上がり、3回連続で失敗すると終了。助走が速いほど高く跳べますが、踏切位置も手前になります。

### ⑥ 400m走
タップの速さでペースを調整。速く走るほどスタミナが急激に減り、45%を切ると失速します。最初から全力だと後半バテるので、PACEメーターの緑ゾーン（8割程度）で巡航し、残り150mから全力スパートが基本戦略です。

### ⑦ 4×100mリレー
バトンを持つ走者を交互タップで走らせます。次走者はチェックマークで自動スタート。「いまだ！」が出たら「バトン」をタップ。ちょうどいい距離で渡すと PERFECT、ゾーンを過ぎるとバトンミスで大きく減速。4匹のメンバーはそれぞれ足の速さが違います。

### 大会モード
- **選手登録**：パグと大会の種類を選ぶ（ショート＝決勝3競技／フル＝決勝7競技）
- **予選**：100m走で6人中3位以内なら決勝進出
- **決勝**：各競技の順位でポイント（1位10・2位8・3位6・4位5・5位4・6位3）
- **表彰式**：合計ポイントで総合順位。上位3匹が表彰台へ。優勝すると花火と紙吹雪
- 途中でやめても、タイトルの「大会のつづきから」で再開できます

### 選手と解放条件
| 選手 | 毛色 | タイプ | 解放条件 |
|---|---|---|---|
| ムギ | フォーンパグ | バランス型 | 最初から |
| スミ | 黒パグ | スピード型 | 最初から |
| アン | アプリコットパグ | パワー型 | 最初から |
| ユキ | 白パグ | ジャンプ型 | 金メダルを合計3個 |
| ギン | シルバーパグ | テクニック型（判定が少し広い・スタミナ多め） | 大会で優勝 |

### 難易度
| | CPU | タイミング判定 | 補助表示 |
|---|---|---|---|
| EASY | 初心者中心 | 広い | あり |
| NORMAL | 中級〜上級者 | 標準 | あり |
| HARD | 上級者＋世界チャンピオン | 狭い（約0.6倍） | なし |

```
pug-olympic/
├── index.html              画面構成（9画面）
├── style.css               スマホ優先のUIスタイル（縦横対応・セーフエリア対応）
├── manifest.json           PWA設定
├── sw.js                   Service Worker（オフライン用キャッシュ）
├── README.md
├── assets/icons/           アプリアイコン（オリジナル）
└── js/
    ├── main.js             起動処理・Service Worker登録
    ├── saveManager.js      LocalStorage保存（型チェック・破損時バックアップ復元）
    ├── soundManager.js     Web Audioで生成する効果音とオリジナルBGM
    ├── inputManager.js     Pointer Events入力・キーボード・左右交互タップ判定
    ├── physics.js          走者の運動モデル・放物運動・数学ユーティリティ
    ├── character.js        パグ5種の定義とCanvas描画（12種類以上のポーズ）
    ├── scoreManager.js     競技データ・世界記録・順位/ポイント・CPU生成・メダル
    ├── gameEngine.js       Canvas・ゲームループ・競技場背景・演出エフェクト
    ├── ceremony.js         表彰式シーン・結果画面の背景
    ├── tournament.js       大会モード（予選・決勝・総合順位・中断/再開）
    ├── ui.js               各画面のUIと画面遷移
    └── competition/
        ├── base.js         競技の基底クラス・レース共通処理
        ├── fieldBase.js    フィールド種目共通（試技ラウンド・記録ボード）
        ├── sprint100.js
        ├── hurdles110.js
        ├── longJump.js
        ├── javelin.js
        ├── highJump.js
        ├── run400.js
        └── relay.js
```

### 新しい競技の追加方法
`js/competition/` に新しいファイルを作り、`PPO.RaceBase`（走る競技）または `PPO.FieldBase`（試技型）を継承して `PPO.registerCompetition('id', { create, howto })` で登録します。`scoreManager.js` の `EVENTS` と `ORDER` に競技情報を追加し、`index.html` と `sw.js` にファイルを追記すれば競技選択に表示されます。

## 公開方法

### GitHub Pages
1. GitHubで新しいリポジトリを作成
2. このフォルダの中身をすべてアップロード（`index.html` がリポジトリ直下に来るように）
3. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

### Netlify
1. https://app.netlify.com にログイン
2. 「Add new site → Deploy manually」を選び、このフォルダをドラッグ＆ドロップ
3. 発行されたURL（`https://xxxx.netlify.app`）で公開されます

どちらも HTTPS なので、PWAとしてインストールできます。

### 更新したとき
`sw.js` の `CACHE` の名前（例：`pugpug-olympic-v1` → `v2`）を変更すると、インストール済みの端末にも新しいファイルが配信されます。

## PWAのインストール方法

### iPhone（Safari）
1. 公開したURLを Safari で開く
2. 下部の共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」を選ぶ
4. ホーム画面の「パグオリ」アイコンから全画面で遊べます

### Android（Chrome）
1. 公開したURLを Chrome で開く
2. 右上のメニュー（︙）→「アプリをインストール」または「ホーム画面に追加」
3. ホーム画面のアイコンから起動

一度開いたあとは、機内モードなどのオフラインでも遊べます。記録はその端末のブラウザ内（LocalStorage）に保存され、ブラウザを閉じても消えません。

## 実装上の補足（仕様に明記がなく、ゲームとして判断した点）

- **単独競技でもCPUと対戦**し、3位以内でメダルを獲得します（メダル数は単独競技＋大会総合の合計）。
- **フライング**は1回目警告、2回目で失格（ゲームとしての遊びやすさを優先）。
- **走り幅跳び・やり投げ**は3回試技のベスト記録。**走り高跳び**はパスなし、3回連続失敗で終了。
- **400m**はトラックを直線スクロールで表現（カーブは省略）。
- **リレー**の受け渡しゾーンは各100m地点の前後10m。次走者のスタートは自動、プレイヤーはバトンを渡すタイミングを操作。
- **予選**は100m走の1レース（6人中3位以内で通過）。
- **世界記録**は、練習した人がほぼ理想的なプレイをして届く値に調整しています（自動プレイのシミュレーションで確認）。
- 音楽・効果音・キャラクター・アイコンはすべてこのプロジェクトのオリジナルで、既存ゲームの素材は使用していません。

## 動作確認済み
